Competition Guidelines

  • You are not required to change the password of the primary auto-login account. Doing so may lock you out.
  • Authorized administrator passwords were correct during the last password audit but are not guaranteed to remain accurate.
  • Do not disable or stop the CSSClient service or process.
  • Do not remove authorized users or their home directories.
  • The image uses UTC. Do not change its time zone, date, or time.
  • Open the current scoring report using the “Scoring Report” desktop icon.
  • JavaScript is required for some scoring-report error messages. Do not disable it.
  • Some security settings may prevent the Stop Scoring application from running. If that happens, suspend the virtual machine. Do not power it on again before deleting it.
